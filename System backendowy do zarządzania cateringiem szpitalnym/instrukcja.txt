# Katering Szpitalny – backendowa aplikacja administracyjna w PHP

## Opis projektu

„Katering Szpitalny” to backendowa aplikacja administracyjna napisana w PHP, przeznaczona do zarządzania procesem obsługi cateringu szpitalnego.

System umożliwia obsługę:

* użytkowników,
* diet,
* zamówień,
* raportów,
* logowania z weryfikacją 2FA,
* eksportu raportów do plików CSV i PDF.

Projekt został przygotowany jako aplikacja demonstracyjna do portfolio/CV. Pokazuje praktyczne wykorzystanie PHP, MySQL, JavaScript, Fetch API, JSON, Bootstrap oraz PHPMailer.

## Jak zalogować się do aplikacji

1. Uruchom aplikację lokalnie w przeglądarce pod adresem:

   `http://localhost/`

2. System automatycznie sprawdzi status sesji użytkownika.

   Jeżeli użytkownik nie jest zalogowany, zostanie przekierowany do strony logowania.

   Jeżeli użytkownik jest już zalogowany, zostanie przekierowany bezpośrednio do kokpitu aplikacji.

3. Na stronie logowania wpisz dane użytkownika:

   Login: `rekrutacja`
   Hasło: `KateringTest123`

4. Kliknij przycisk logowania.

5. System wyśle sześciocyfrowy kod 2FA na skrzynkę:

   `kateringtest5@gmail.com`

6. Zaloguj się na testową skrzynkę e-mail:

   E-mail: `kateringtest5@gmail.com`
   Hasło: `TestKatering123`

7. Otwórz wiadomość z kodem logowania.

8. Przepisz kod do formularza 2FA w aplikacji.

9. Po poprawnym wpisaniu kodu system przekieruje użytkownika do panelu administracyjnego.

## Główne moduły aplikacji

### 1. Panel główny

Po zalogowaniu użytkownik trafia do panelu administracyjnego. Panel pozwala przejść do głównych sekcji systemu:

* użytkownicy,
* diety,
* zamówienia,
* raporty.

---

### 2. Użytkownicy

Moduł użytkowników pozwala zarządzać kontami w systemie.

Dostępne funkcje:

* dodawanie użytkownika,
* edycja użytkownika,
* usuwanie użytkownika,
* akceptacja użytkownika,
* zmiana statusu użytkownika,
* przypisanie roli użytkownika.

---

### 3. Diety

Moduł diet pozwala zarządzać dietami szpitalnymi.

Dostępne funkcje:

* dodawanie diety,
* edycja diety,
* usuwanie diety,
* akceptacja diety,
* oznaczenie diety jako specjalnej,
* dodanie ograniczeń i alergenów,
* dodanie opisu oraz notatek.

Przykładowe pola diety:

* nazwa diety,
* kod diety,
* oddział,
* dieta specjalna,
* ograniczenia / alergeny,
* opis,
* uwagi.

---

### 4. Zamówienia

Moduł zamówień pozwala zarządzać zamówieniami cateringowymi dla oddziałów szpitalnych.

Dostępne funkcje:

* dodawanie zamówienia,
* edycja zamówienia,
* usuwanie zamówienia,
* akceptacja zamówienia,
* przypisanie zamówienia do oddziału,
* oznaczenie zamówienia jako specjalnego,
* dodanie ograniczeń i opisu.

Przykładowe pola zamówienia:

* nazwa zamówienia,
* kod zamówienia,
* oddział,
* liczba porcji,
* zamówienie specjalne,
* ograniczenia / alergeny,
* opis,
* uwagi.

---

### 5. Raporty

Aplikacja zapisuje historię ważnych operacji wykonywanych w systemie.

Dostępne raporty:

* raport logowania,
* raport użytkowników,
* raport diet,
* raport zamówień.

Raporty pokazują:

* kto wykonał operację,
* jaki był typ operacji,
* kiedy wykonano akcję,
* jakiego obiektu dotyczyła operacja,
* jaki jest status danych.

Dane raportów można wyświetlać na ekranie w tabeli lub w formie akordeonu. System posiada również eksport raportów do plików CSV i PDF.

## Jak działa aplikacja technicznie

Aplikacja działa w prostym modelu komunikacji między frontendem, backendem i bazą danych.

Frontend wysyła dane z formularzy za pomocą JavaScript Fetch API do plików PHP. Backend wykonuje operacje na bazie danych MySQL za pomocą PDO, a następnie zwraca odpowiedź w formacie JSON.

Schemat działania:

`Formularz HTML → JavaScript Fetch API → PHP → MySQL → JSON → Aktualizacja widoku`

Dzięki temu część operacji działa dynamicznie, bez klasycznego przeładowywania całej strony.

## Instrukcja uruchomienia lokalnie

### 1. Instalacja XAMPP

Należy zainstalować XAMPP i uruchomić:

* Apache,
* MySQL.

---

### 2. Skopiowanie plików projektu

Pliki aplikacji należy wkleić bezpośrednio do katalogu:

`C:\xampp\htdocs`

Projekt nie powinien znajdować się w dodatkowym folderze.

Poprawna struktura:

`C:\xampp\htdocs\index.php`
`C:\xampp\htdocs\window\login.php`
`C:\xampp\htdocs\window\dashboard.php`
`C:\xampp\htdocs\core\config\db.php`
`C:\xampp\htdocs\assets\css\...`
`C:\xampp\htdocs\assets\js\...`

Dzięki temu aplikacja będzie dostępna pod adresem:

`http://localhost/`

---

### 3. Utworzenie bazy danych

W przeglądarce należy wejść na:

`http://localhost/phpmyadmin`

Następnie należy utworzyć bazę danych, np.:

`catering`

---

### 4. Import bazy danych

W phpMyAdmin należy:

1. Wybrać bazę danych `catering`.
2. Przejść do zakładki „Import”.
3. Wybrać plik `.sql` z bazą projektu dostępny w folderze z projektem.
4. Kliknąć „Wykonaj” albo „Importuj”.

Po imporcie powinny pojawić się tabele odpowiedzialne za użytkowników, diety, zamówienia, raporty oraz kody logowania 2FA.

---

### 5. Konfiguracja połączenia z bazą

W pliku:

`core/config/db.php`

należy sprawdzić dane połączenia z bazą danych.

Przykład dla XAMPP:

* host: `localhost`,
* użytkownik: `root`,
* hasło: puste,
* baza danych: `catering`.

---

### 6. Konfiguracja wysyłki e-mail

Aplikacja wykorzystuje PHPMailer do wysyłania kodów 2FA.

Należy sprawdzić konfigurację poczty odpowiedzialnej za wysyłanie wiadomości e-mail, w szczególności:

* adres nadawcy,
* hasło lub hasło aplikacji,
* host SMTP,
* port SMTP,
* typ szyfrowania.

Bez poprawnej konfiguracji poczty kod 2FA nie zostanie wysłany.

---

### 7. Uruchomienie aplikacji

Po uruchomieniu Apache i MySQL aplikację można otworzyć w przeglądarce pod adresem:

`http://localhost/`

Po wejściu na ten adres system automatycznie sprawdzi sesję użytkownika.

Jeżeli użytkownik nie jest zalogowany, aplikacja przekieruje go do strony logowania.

Jeżeli użytkownik jest zalogowany, aplikacja przekieruje go bezpośrednio do kokpitu aplikacji.
